# Security reports

Do not post credentials, confidential models, private paths, or an unpatched
security exploit in a public issue. Use GitHub's **Security → Report a
vulnerability** feature for a private report to the maintainer.

Describe the affected version, impact, and minimal reproduction without real
credentials or private assets. Betopo currently has no guaranteed response time.

The current 0.1.x release line is the focus of maintenance. Verify the source
repository and release checksums before installing. Betopo runs locally and
does not need a GitHub token, account sign-in, or network access at runtime.
